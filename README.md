# PyWall - Simple Windows Firewall Manager

## Описание
Приложение для управления фаерволом Windows через графический интерфейс. Позволяет добавлять, удалять и применять правила блокировки/разрешения сетевых портов.

## Стек технологий
- Python 3
- Tkinter (GUI)
- JSON (хранение конфигурации)
- netsh (управление Windows Firewall)
- PyInstaller (сборка в exe)

## Как запустить
1. Запустить PyWall.exe от имени администратора.
2. Ввести название правила, порт (например 80), выбрать действие (block/allow) и направление (in/out).
3. Нажать "Добавить в список".
4. Выделить правило в таблице и нажать "Применить выбранное".

## Важно
Приложение требует прав администратора для внесения изменений в системный фаервол Windows.
