#PyWall - Simple Windows Firewall Manager

**PyWall** — это графический менеджер брандмауэра Windows, написанный на Python. Программа позволяет в реальном времени анализировать сетевой трафик, блокировать доступ к конкретным IP-адресам, доменам и портам, а также вести детальный журнал событий.

Проект создан в рамках курсовой работы по дисциплине «Сетевое администрирование» (или замени на свой предмет).

## Основные возможности

*   **Блокировка по IP-адресу:** Мгновенная блокировка любого IPv4-адреса на уровне ОС (через `netsh advfirewall`).
*   **Блокировка по доменному имени:** Автоматическое разрешение домена в IP-адреса (включая подсети для крупных сервисов вроде GitHub, YouTube).
*   **Блокировка по портам:** Перекрытие доступа к конкретным портам (например, 80 или 443), что позволяет полностью заблокировать браузер.
*   **Анализ трафика в реальном времени:** Использование `scapy` для подсчета общего количества пакетов и вывода ТОП-3 самых активных IP-адресов.
*   **Защита на двух уровнях:** 
    *   `netsh` (системный уровень) — жесткая блокировка.
    *   `scapy` (перехват пакетов) — мгновенный сброс соединений (RST) для быстрой реакции.
*   **Логирование:** Все действия и результаты анализа записываются в файл `logs/app.log` с возможностью просмотра прямо из интерфейса (Live-режим).
*   **Темная тема:** Современный и приятный глазу интерфейс.

---

## Технологический стек

*   **Язык:** Python 3.8+
*   **GUI:** Tkinter (стандартная библиотека) + ttk
*   **Сетевой анализ:** Scapy
*   **Системная блокировка:** `netsh advfirewall` (вызов через `subprocess`)
*   **Работа с доменами:** `socket` (DNS-резолвинг)

## Установка и запуск

### 1. Требования
*   Windows 10/11
*   Права администратора (обязательно, так как программа управляет брандмауэром).
*   Установленный **Npcap** (или WinPcap) для работы `scapy`.

### 2. Установка зависимостей
Откройте терминал в папке с проектом и выполните:
```bash
pip install scapy pillow
```
